# Nirikshak · निरीक्षक (public demo)

Audit finance-influencer videos, check forwarded WhatsApp "tips", profile creators and ask questions,
in English or Hindi, with every name and registration number checked against SEBI's public registers.

This hosted demo uses free cloud AI (Groq, with Google Gemini as backup) through server-side keys (rate-limited per visitor). The full version runs
entirely on your own computer with local models: see the GitHub repository.

Awareness tool only. Not investment advice.
